# Phase 3 – Project Design Phase

## Project Title
LegalEase – AI-Powered Legal Document Generator

## System Design
The system accepts legal case details from the user and uses AI to generate a structured legal document.

## Main Modules

### 1. User Input Module
- Collects case details.
- Collects user and document information.

### 2. Document Type Module
- Allows the user to select the required legal document type.

### 3. AI Processing Module
- Processes the information provided by the user.
- Generates suitable legal document content.

### 4. Document Generation Module
- Creates the final structured document.
- Allows the user to view the generated document.

### 5. Download Module
- Allows the generated document to be saved or downloaded.

## Basic Flow

User Input
↓
Select Document Type
↓
AI Processing
↓
Generate Legal Document
↓
View / Download Document

## Expected Result
The system should generate a clear and properly structured legal document from the information provided by the user.
