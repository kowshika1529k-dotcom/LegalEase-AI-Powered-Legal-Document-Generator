# Phase 2 – Requirement Analysis

## Project Title
LegalEase – AI-Powered Legal Document Generator

## Problem Statement
Creating legal documents manually is difficult and time-consuming. 
Users may not know the correct legal format and important details may be missed.

## Proposed Solution
LegalEase is an AI-powered application that helps users generate legal documents easily by entering the required information.

## Target Users
- Students
- Common people
- Small businesses
- Legal professionals

## Functional Requirements
- User can enter case details.
- User can select the type of legal document.
- System generates a structured legal document.
- User can view the generated document.
- User can download or save the document.

## Non-Functional Requirements
- Easy to use
- Fast response
- Secure handling of user data
- Simple and clear interface

## Input
- Case details
- Person details
- Document type
- Other required information

## Output
A properly structured legal document generated based on the given information.

## Technologies
- Python
- AI/ML
- Generative AI
- HTML/CSS
- GitHub
