# Phase 8 – Project Demonstration

## Project Title
LegalEase – AI-Powered Legal Document Generator

## Demonstration Overview
The project demonstration explains how the LegalEase system works and shows the main features of the application.

## Demonstration Steps

1. Open the LegalEase application.
2. Enter the required user details.
3. Select the required document type.
4. Enter the necessary case information.
5. Submit the information.
6. Show the AI-generated legal document.
7. Check the document structure.
8. Show the save or download option.

## Main Features Demonstrated

- User input
- Document type selection
- AI processing
- Legal document generation
- View generated document
- Save or download document

## Expected Demonstration Result
The demonstration should show that LegalEase can accept user information and generate a structured legal document.
